## 🚀 Featured Projects

### 🕹️ [2D Game Engine](https://github.com/o-hesham/2DGameEngine)
> A high-performance 2D game engine built with **C++23**, **SDL2**, and a custom **ECS** architecture.

- Custom Entity Component System with cache-efficient contiguous memory pools
- Lua scripting for level design and entity behavior (Sol2 bindings)
- Full rendering pipeline: sprites, animations, tilemaps, text, health bars
- Type-safe event bus for decoupled system communication
- ImGui debug overlay, AABB collision, projectile system, and camera following

---

### ⚡ [2D Physics Engine](https://github.com/o-hesham/2DPhysicsEngine)
> A comprehensive 2D rigid body physics simulation built with **C++** and **SDL2**.

- Rigid body dynamics with linear and angular motion (6-DOF)
- Shape support: circles, boxes, custom polygons
- SAT-based collision detection with restitution and friction response
- Constraint solver for joints and contact constraints (iterative method)
- Force generators: drag, friction, gravity, springs

---

### 🎨 [3D Renderer](https://github.com/o-hesham/3DRenderer)
> A CPU software 3D renderer written in **C (C99)** using SDL2.

- Full software rasterization pipeline (no GPU APIs)
- OBJ mesh loading with vertex positions, normals, and UVs
- Backface culling, view-frustum clipping (6 planes), z-buffer
- Shading modes: wireframe, flat, Gouraud, textured
- Free-look camera with relative mouse mode

---

### 🧵 [Cloth Physics Simulation](https://github.com/o-hesham/ClothPhysicsSimulation)
> Real-time cloth simulation using particle-based physics in **C++** with **SDL2**.

- Particle system with spring-damper constraints for realistic cloth behavior
- Verlet integration for stable, frame-rate-independent simulation
- Interactive mouse controls: grab, drag, and cut cloth in real time

---

### 🔦 [Ray Tracer](https://github.com/o-hesham/RayTracer)
> A C++17 ray tracer that renders a scene to a PPM image.

- Diffuse, metal, and dielectric (glass) materials
- Anti-aliased rendering with multiple samples per pixel
- Gamma-corrected output, depth of field via defocus disk camera model
- Randomized multi-sphere scene generation
